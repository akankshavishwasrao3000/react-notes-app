# React Notes App 📝

A simple and interactive Notes App built using **React.js** and **Tailwind CSS**.

The application allows users to create notes by entering a title and details. Added notes are displayed in the Recent Notes section, where users can delete notes when they are no longer needed.

## 🚀 Features

- Add a new note
- Enter note title and details
- Display notes dynamically
- Delete notes
- Responsive layout
- Styled using Tailwind CSS
- React state management using `useState`

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- HTML5

## 📚 React Concepts Used

This project helped practice:

- `useState`
- Controlled inputs
- `onChange`
- Form submission
- Event handling
- Array state
- `map()`
- `splice()`
- Spread operator
- Conditional/dynamic rendering
